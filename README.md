# RealitySync (リアリティ・シンク)

## 概要

RealitySyncは、「理想のスケジュール」と「現実の行動・体調」のギャップを記録・可視化し、自分にとって本当に最適な生活リズムを見つけるためのスケジューリングアプリです。

私たちが頭で考える「完璧なスケジュール」は、その時の気分、体調、突発的な出来事によって崩れることがあります。本アプリは、予定通りにいかなかったことを「失敗」と捉えるのではなく、次の計画に生かすための「貴重なデータ」として記録します。

## 現在実装されている主要機能

### 1. 日付ごとの理想スケジュール

- 前日 / 翌日へ移動
- 任意の日付を選択
- 今日へワンタップで戻る
- 日ごとに独立した予定を保存
- 予定の追加 / 編集 / 削除
- 予定ごとに開始時刻、予定時間、カテゴリ、想定負荷を設定

### 2. 理想と現実のデュアル・トラッキング

- **理想の計画:** 日付ごとのタイムライン上に理想のスケジュールを設定します。
- **現実の記録:** 各予定に対して、実際にどう行動したかを記録します。
  - 予定通り実行した
  - 別の活動へ変更した
  - スキップした
- 実際に費やした時間、実負荷、終了時の気分も記録できます。
- 予定を後から編集しても、すでに記録済みの実際の活動名・カテゴリ・時間は別の実績スナップショットとして保持します。

### 3. ギャップ分析

- 想定負荷と実負荷の波を可視化
- 理想時間と現実時間をカテゴリ別に比較
- 予定通り / 変更 / スキップ / 未記録の件数を可視化
- 予定外に積み上がった実際の活動も表示

RealitySyncでは、予定時間を推測で「実際にやった時間」として扱いません。現実側のデータは、ユーザーが明示的に記録した内容だけを使用します。

## 使い方

1. ヘッダーの日付ナビゲーションで記録したい日を選びます。
2. **計画**タブで「予定を追加する」から理想のスケジュールを作ります。
3. 必要に応じて予定カードをタップし、内容を編集または削除します。
4. **記録**タブで各予定をタップし、「予定通り / 変更 / スキップ」、実負荷、気分、実際に費やした時間を入力します。
5. **分析**タブで、その日の理想と現実の差を確認します。

データはブラウザの `localStorage` に日付別で保存され、リロード後も保持されます。

### 旧デモ版からの移行

旧 `v1` 保存データにユーザーが実際に記録した変更がある場合は、初回起動日のデータとして `v2` 形式へ移行します。

旧デモを一度も触っていない初期サンプルデータは製品データへ持ち込まず、新しい製品版は空のスケジュールから始まります。

## 設計上の大事な方針

RealitySyncは、予定との差を「失敗」として裁くのではなく、現実を次の計画に反映するためのデータとして扱います。

そのため、未記録の時間を推測で実績に加算したり、十分なデータなしに因果関係を断定したりしません。

**計画から「現実」を捏造しない。実際の行動・時間・気分・負荷は、明示的な記録がある場合だけ現実として扱う。**
