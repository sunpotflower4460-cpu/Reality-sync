# RealitySync (リアリティ・シンク)

## 概要

RealitySyncは、「理想のスケジュール」と「現実の行動・体調」のギャップを記録・可視化し、自分にとって本当に最適な生活リズムを見つけるための次世代スケジューリングアプリです。

私たちが頭で考える「完璧なスケジュール」は、その時の気分、体調、突発的な出来事によって崩れることがよくあります。本アプリは、予定通りにいかなかったことを「失敗」と捉えるのではなく、「貴重なデータ」として記録します。

## 主要機能

### 1. 理想と現実のデュアル・トラッキング

- **理想の計画:** タイムライン上に理想のスケジュールを設定します。
- **現実の記録:** 時間になった際（または事後に）、実際にどう行動したか、その時の「気分・体調」はどうだったかを記録します。
  - 予定通り実行できたか？
  - 気分が乗らず、別の活動に変更したか？
  - 体調不良などでスキップしたか？

### 2. ギャップ分析（グラフ機能）

- **達成率の可視化:** 理想の予定に対して、どれだけ計画通りに行動できたかを可視化します。
- **現実時間の可視化:** 予定時間を推測で実績扱いせず、実際に記録した時間をカテゴリ別に積み上げます。

### 3. 習慣の波及効果（シナジー）分析

- 「習慣A（例：朝のランニング）」を行った日と、行わなかった日において、その後の「習慣B（例：午後の集中ワーク）」の達成率や気分にどのような違いが出るかを比較・分析する構想です。
- 十分な記録が蓄積してから相関を評価し、少数データだけで因果関係を断定しない方針です。

## デモ版の使い方

- **計画:** 初期デモスケジュールと想定負荷を確認します。予定追加は次段階の実装対象です。
- **記録:** 各予定をタップし、「予定通り / 変更 / スキップ」、実負荷、気分、実際に費やした時間を記録します。
- **分析:** 理想時間と現実時間、予定の達成度、予定外の積み重ねを確認します。
- 記録内容はブラウザの `localStorage` に保存され、リロード後も保持されます。

## 今後の展望（製品版に向けた構想）

- **プッシュ通知機能:** 予定時刻の5分前にスマートフォンやPCへ通知し、その場で現在の気分と実際の行動を入力できる機能。
- **AIアドバイス:** 蓄積されたデータから、観測事実をもとに次の計画を調整する提案を行う機能。
- **日別・週別分析:** 1日単位だけでなく、曜日・週・期間で理想と現実の差を比較する機能。
- **習慣シナジー分析:** 十分なサンプル数を確保した上で、特定習慣とその後の行動・気分・負荷との関係を見る機能。

## 設計上の大事な方針

RealitySyncは、予定との差を「失敗」として裁くのではなく、現実を次の計画に反映するためのデータとして扱います。

そのため、未記録の時間を推測で実績に加算したり、十分なデータなしに因果関係を断定したりしない方針で実装しています。
