# RealitySync (リアリティ・シンク)

## 概要

RealitySyncは、「理想のスケジュール」と「現実の行動・体調」のギャップを記録・可視化し、自分にとって本当に最適な生活リズムを見つけるためのスケジューリングアプリです。

私たちが頭で考える「完璧なスケジュール」は、その時の気分、体調、突発的な出来事によって崩れることがあります。本アプリは、予定通りにいかなかったことを「失敗」と捉えるのではなく、次の計画に生かすための「貴重なデータ」として記録します。

## 現在実装されている主要機能

### 1. 日付ごとの理想スケジュール

- 前日 / 翌日へ移動
- 任意の日付を選択
- 今日へワンタップで戻る
- 日ごとに独立した予定を保存
- 予定の追加 / 編集 / 削除
- 予定ごとに開始時刻、予定時間、カテゴリ、想定負荷を設定
- 前日の予定をワンタップでコピー
- 平日 / 休日 / 制作日など、1日の予定を名前付きテンプレートとして保存・再利用

前日コピーとテンプレートには計画データだけを使い、過去日の実績・気分・実負荷・理由はコピーしません。

### 2. 理想と現実のデュアル・トラッキング

各予定に対して、次の現実データを明示的に記録できます。

- 予定通り / 別の活動へ変更 / スキップ
- 実際に開始した時刻（不明なら空欄のまま保持）
- 実際に費やした時間
- 実負荷
- 終了時の気分
- 変更 / スキップした理由（任意）

予定を後から編集しても、すでに記録済みの実際の活動名・カテゴリ・時間は別の実績スナップショットとして保持します。

### 3. 日次ギャップ分析

- 想定負荷と実負荷の波を可視化
- 理想時間と現実時間をカテゴリ別に比較
- 予定通り / 変更 / スキップ / 未記録の件数を可視化
- 予定外に積み上がった実際の活動も表示
- 実開始時刻が記録されている場合、現実の負荷を本当の開始時刻に配置
- 開始時刻が不明な実績は、予定時刻へ推測配置せず時間軸から除外した件数を明示

### 4. 週間レビュー

分析タブは「日 / 週」を切り替えられ、選択日を含む月曜〜日曜を1週間として集計します。

- 週全体の記録率と、記録済みの中での予定通り率
- 理想時間と現実時間の週合計
- 予定開始時刻と実開始時刻の平均ズレ / 平均絶対ズレ
- この週の曜日別の記録率、理想時間、現実時間、開始時刻のズレ
- カテゴリ別の理想時間 vs 現実時間
- 変更 / スキップ理由の頻度
- 予定通り / 変更 / スキップごとの平均実負荷
- 終了時の気分の件数
- 前週 / 翌週への移動

RealitySyncは、1週間だけを見て「月曜日は苦手」のような恒常的な曜日傾向を断定しません。週間画面はその週の観測比較として扱い、曜日傾向や習慣相関は複数週のサンプルが蓄積してから評価します。

また、実開始時刻は不明なら不明のまま扱います。予定時刻から実開始時刻を推測せず、現時点のデータモデルでは方向を安全に判定できない深夜跨ぎの可能性がある大きな時刻差も、開始時刻平均から除外します。

RealitySyncでは、予定時間や予定時刻を推測で「実際の現実」として扱いません。現実側のデータは、ユーザーが明示的に記録した内容だけを使用します。

## 使い方

1. ヘッダーの日付ナビゲーションで記録したい日を選びます。
2. **計画**タブで予定を作るか、前日の予定 / 保存済みテンプレートを利用します。
3. 必要に応じて予定カードをタップし、内容を編集または削除します。
4. **記録**タブで各予定をタップし、実際の行動・開始時刻・実時間・負荷・気分・理由を記録します。
5. **分析**タブの「日」でその日の差を確認し、「週」で同じ週の複数日を比較します。

日別データとテンプレートはブラウザの `localStorage` に保存され、リロード後も保持されます。

### 旧デモ版からの移行

旧 `v1` 保存データにユーザーが実際に記録した変更がある場合は、初回起動日のデータとして `v2` 形式へ移行します。

旧デモを一度も触っていない初期サンプルデータは製品データへ持ち込まず、新しい製品版は空のスケジュールから始まります。

## 設計上の大事な方針

RealitySyncは、予定との差を「失敗」として裁くのではなく、現実を次の計画に反映するためのデータとして扱います。

そのため、未記録の時間や開始時刻を推測で実績に加算したり、十分なデータなしに因果関係を断定したりしません。

**計画から「現実」を捏造しない。実際の行動・時間・開始時刻・気分・負荷・理由は、明示的な記録がある場合だけ現実として扱う。**
