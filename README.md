# RealitySync（リアリティ・シンク）

## 概要

RealitySyncは、「理想のスケジュール」と「現実の行動・体調」のギャップを記録・可視化し、自分にとって本当に最適な生活リズムを見つけるための次世代スケジューリングアプリです。

私たちが頭で考える「完璧なスケジュール」は、その時の気分、体調、突発的な出来事によって崩れることがよくあります。本アプリは、予定通りにいかなかったことを「失敗」と捉えるのではなく、「貴重なデータ」として記録します。

## 主要機能

### 1. 理想と現実のデュアル・トラッキング

- **理想の計画:** タイムライン上に理想のスケジュールを設定します。
- **現実の記録:** 時間になった際（または事後に）、実際にどう行動したか、その時の「気分・体調」はどうだったかを記録します。
  - 予定通り実行できたか？
  - 気分が乗らず、別の活動（例：読書→動画視聴）に変更したか？
  - 体調不良でスキップしたか？

### 2. ギャップ分析（グラフ機能）

- **達成率の可視化:** 理想の予定に対して、どれだけ計画通りに行動できたかを日別・週別でグラフ化します。
- **変更理由の分析:** 予定を変更した主な要因（気分、体調、急用など）を可視化し、自分の傾向を把握します。

### 3. 習慣の波及効果（シナジー）分析

- 「習慣A（例：朝のランニング）」を行った日と、行わなかった日において、その後の「習慣B（例：午後の集中ワーク）」の達成率や気分にどのような違いが出るかを比較・分析します。
- これにより、「朝運動した方が、午後の仕事のパフォーマンスが上がる（または疲れて下がる）」といった、自分だけの行動パターンを発見できます。

## 現在のデモ実装

現在のプロトタイプでは、次の範囲を実際に操作できます。

- 計画・記録・分析の3タブ
- 初期スケジュールの表示
- 「予定通り / 変更 / スキップ」の実績記録
- 気分と実ストレス（0〜100）の記録
- 想定ストレスと実ストレスの波形比較
- 理想時間と現実時間のカテゴリ別比較
- 予定外に発生した活動の積み上げ
- ブラウザ内への記録保存（localStorage）

予定の新規追加、日別・週別履歴、変更理由の詳細分析、習慣シナジー分析、通知、AIアドバイスは今後の実装対象です。

## デモ版の使い方

### 「計画」タブ

- 初期設定された理想のスケジュールを確認できます。
- 「予定を追加する」は現在デモ用プレースホルダーです。

### 「記録」タブ

- 各予定を押し、予定通り・変更・スキップを記録します。
- 変更した場合は、代わりに行ったこととカテゴリを入力します。
- 実際のストレス・負荷と終了時の気分を記録できます。

### 「分析」タブ

- 理想と現実のカテゴリ別時間を比較できます。
- 予定外の活動も「予定外の積み重ね」として可視化されます。
- 習慣シナジー分析は、十分な履歴データを扱えるようになった段階で実装予定です。

## 今後の展望（製品版に向けた構想）

- **プッシュ通知機能:** 予定時刻の5分前にスマートフォンやPCに通知を送り、その場で現在の気分と実際の行動をワンタップで入力できる機能。
- **AIアドバイス:** 蓄積されたデータから「水曜日の午後は体調を崩しやすいので、軽めのタスクを入れましょう」などの提案を行う機能。
