# RealitySync（リアリティ・シンク）説明書

## 概要

RealitySyncは、「理想のスケジュール」と「現実の行動・体調」のギャップを記録・可視化し、自分にとって本当に無理のない生活リズムを見つけるためのスケジューリングアプリです。

予定通りにいかなかったことを失敗として扱うのではなく、「なぜズレたのか」「実際には何をしたのか」「どの程度の負荷だったのか」を次の計画へ活かすためのデータとして残します。

## 3つのコア機能

### 1. 計画（Plan）

- 日付ごとに理想のスケジュールを作成
- 開始時刻、予定時間、カテゴリ、想定負荷を設定
- 予定の追加 / 編集 / 削除
- 前日の予定をコピー
- 1日の予定を名前付きテンプレートとして保存・再利用

コピーやテンプレートに含まれるのは計画だけです。過去の実績、気分、実負荷、変更理由、実開始日時は新しい日へコピーしません。

### 2. 記録（Track）

各予定に対して、現実を次の3状態で記録できます。

- 予定通り実行した
- 別の活動へ変更した
- スキップした

さらに、以下を明示的に記録できます。

- 実際の活動名 / カテゴリ
- 実際に開始した日付
- 実際に開始した時刻
- 実際に費やした時間
- 実際の負荷
- 終了時の気分
- 変更 / スキップした理由

開始時刻を覚えていない場合は空欄のままで構いません。RealitySyncは予定時刻を実開始時刻として補完しません。

開始日時を記録した場合、たとえば「23:50予定 → 翌日00:10開始」のような深夜跨ぎも、実開始日を使って正確なズレとして扱います。

旧バージョンで開始時刻だけ保存されていた記録は、開始日を推測で補完せず「開始日不明の旧記録」として保持します。

### 3. 分析（Analytics）

分析タブには **日 / 週 / 月** の3つの時間スケールがあります。

#### 日

- カテゴリ別の理想時間 vs 現実時間
- 予定通り / 変更 / スキップ / 未記録の件数
- 想定負荷と実負荷の時間軸比較
- 実開始日時がある場合は、本当の時間位置へ現実の負荷を配置
- 前日 / 翌日開始も日付を使って区別

開始日時が足りない記録を、予定時刻へ推測配置することはありません。

#### 週

選択日を含む月曜〜日曜を1週間として集計します。

- 記録率
- 記録済みの中での予定通り率
- 理想時間 / 現実時間
- 開始日時の平均ズレ / 平均絶対ズレ
- この週の曜日別比較
- カテゴリ別の理想 vs 現実
- 変更 / スキップ理由
- 結果別の平均実負荷
- 気分件数

1週間のデータだけを使って「月曜だから崩れる」のような恒常的な曜日傾向は断定しません。

#### 月

選択日を含むカレンダー月を集計します。

- 月全体の記録率 / 予定通り率
- 月間の理想時間 / 現実時間
- 月間の開始日時ズレ
- 週ごとの推移
- 同じ曜日を複数回まとめた曜日別観測
- 曜日ごとのサンプル数
- カテゴリ別の月間 理想 vs 現実
- 月間の変更 / スキップ理由

曜日別の数値は「この月に観測された違い」です。曜日が原因で行動が変化したとは断定しません。

## RealitySyncが守るデータ原則

RealitySyncの中心原則は、**計画から現実を捏造しないこと**です。

そのため、次の処理を行いません。

- 予定時間を実時間として自動採用する
- 予定時刻を実開始時刻として自動採用する
- 開始時刻しかない旧記録へ、開始日を推測で付与する
- 少ない曜日サンプルから恒常傾向を断定する
- 負荷や気分と予定変更が同時に起きたことだけで、原因と結果を決める

現実側の行動・時間・開始日時・気分・負荷・理由は、ユーザーが明示的に残した記録だけを使用します。

## このアプリが目指すもの

RealitySyncは「理想通りに行動できない自分」を責めるためのツールではありません。

「どこで計画と現実がズレるのか」「どのくらいの計画なら無理なく続くのか」「どんな変更が繰り返し起きているのか」を、日・週・月という複数の時間スケールで客観的に観察し、現実の自分に合う計画へ少しずつ近づけるためのパートナーを目指します。

将来的な習慣シナジーやAI提案についても、十分な縦断データが蓄積し、統計的に防御できる範囲から段階的に解放します。
